# Glossário — manita-site

| Termo | Significado | Onde aparece |
|---|---|---|
| app Google | O cliente OAuth da Manita no Google Cloud, que pede acesso a Gmail, Drive, Planilhas, Agenda e Contatos | tela de consentimento |
| LGPD | Lei nº 13.709/2018, citada na seção 9 da política | `privacidade.html` |
| Manita | A assistente administrativa privada do dono (repositório `LeoKuli/assistente`) | as duas páginas |
| Pages | GitHub Pages, que publica a `main` deste repositório em `leokuli.github.io/manita-site` | ADR 0001 |
| tela de consentimento | A tela do Google em que o titular autoriza o acesso; aponta para estas páginas | ADR 0001 |
| Uso Limitado | "Limited Use": requisito da Política de Dados do Usuário das APIs do Google | `privacidade.html`, seção 8 |
